## Project Summary 
The aim of this project was to design, build and test a battery-powered mouse that could detect the wire track, steer itself, and complete the course reliably within the project week. I wanted the final system to be fast enough to be competitive, but still stable enough to finish a lap consistently. To do that, the work had to be planned clearly from the start so the sensing, control, motor drive, testing, and documentation could all move forward without wasting time.
